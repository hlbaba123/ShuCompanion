# 架构

Leader 将用户要求整理为任务合同，确定活动、章节、关卡、难度和交付终点。目录 Agent 用真实来源建立关卡范围，研究 Agent 消费这些范围并结合本地 Box 核对作业。MAA Agent 消费已核实结果，视觉观察提供当前画面，诊断 Agent 提供只读检查。

SQLite 保存任务、代际、委派、请求回执与动作账本，LangGraph checkpoint 保存流程进度。UI 用任务身份展示进度与历史。任务变更使旧输入权限失效，已提交而未核实的动作保留待对账状态。

图像识别优先使用本地 MaaFramework OCR、模板及几何测量，证据不足时调用独立视觉客户端。每次输入绑定窗口身份、当前截图和权限，通过唯一的桌面工作进程执行，随后核对实际结果。操作截图与任务记录在本机数据目录中。

代码沿用截图与可见键鼠操作路径，实际游戏战斗交给外部安装的 MAA。本文描述已存在的设计，具体版本完成情况以验证记录为准。
