# 公开发布核查边界

本次按文件和实际嵌入代码检查隐私，并补齐可查到的分发许可。结果以根目录privacy-check.json和SOURCE清单中的具体哈希为范围，不能作为“任何用途均不会违法”的承诺。

已移除旧游戏角色参考皮肤及图标、未使用且无来源登记的两张按钮截图；公开版只保留使用者声明自行新设计的男女两款。AI生成、免费、求职展示或“仅供学习”本身均不构成对第三方角色/图片的授权。参考图原始权利仍以实际创作与授权证据为准。

程序不分发MAA可执行文件或完整游戏，未发现读取游戏内存、加载游戏内DLL、绕过游戏登录或使用内部账户协议的实现。截图/操作自动化仍可能受运营协议限制；鹰角[游戏协议](https://user.hypergryph.com/protocol/plain/ak/service)第6.2(16)条约束第三方软件/辅助工具，不能因使用MAA或MaaFramework就认定得到游戏官方授权。违反协议与构成刑事犯罪不是同一个结论，本审查不作刑事定性。

依赖许可证、版权与对应源码访问应随实际Release保留；项目自身代码的再分发授权尚由作者选择，没有替作者自动加MIT/GPL。公开可查看不等于已获得任意用途的开放源代码许可。

可查证依据：[著作权法](https://ipc.court.gov.cn/zh-cn/news/view-6244.html)、[Qt官方许可义务](https://www.qt.io/development/open-source-lgpl-obligations)、[MaaFramework固定版许可](https://github.com/MaaXYZ/MaaFramework/blob/v5.15.0/LICENSE.md)。有授权或协议适用争议时，应由权利方或专业法律审查确认；本次自动和人工代码检查不能消除这一边界。
